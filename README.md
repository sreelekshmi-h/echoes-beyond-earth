
# 🌌 Echoes Beyond Earth

**They left. Their legacy remains.**

Echoes Beyond Earth is an interactive digital museum that explores the stories of human-made machines left on the Moon and Mars. Discover their missions, scientific contributions, and what remains of them today.

## 🚀 Features

- **Explore:** Discover equipment and spacecraft left on the Moon and Mars.
- **Mission Stories:** Learn about the purpose, journey, and legacy of each machine.
- **Timeline:** Explore important milestones in lunar and Martian exploration.
- **Interactive Experience:** Navigate a space-themed interface with an animated comet.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
